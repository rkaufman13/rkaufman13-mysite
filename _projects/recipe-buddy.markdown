I had a very specific idea, which was that I wanted to be able to collect the recipes shared by my potluck buddies in one place. Brookland Dish is the result.

Recipes shared to our listserv are detected by the recipe-buddy-bot, sent to a backend server stood up with FastAPI, and turned into Markdown files, which are then posted to a Github Pages site generated with Jekyll.

A very fast, fun, hyperspecific project.
